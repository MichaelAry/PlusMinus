# Plot Editor в PlusMinus Studio

Откройте [готовый пример](plot-examples/README.md) в Studio 4 или Studio 5.
Редактор строит график вещественной функции `y = f(x)` и отображает таблицы
координат в той же области. Каждый ряд имеет имя, цвет и флажок видимости.

## Формулы и таблицы

- Формулы поддерживают десятичные числа, `x`, параметры `a`, `b`, `c`,
  операции `+ - * / ^`, круглые скобки, `sin`, `cos` и `pow`.
  Аргументы тригонометрических функций задаются в радианах. В
  десятичном литерале перед точкой нужна цифра, например `0.5`.
- Возведение в степень правоассоциативно и имеет приоритет над унарным
  минусом. Поэтому `2^3^2` даёт 512, `-2^2` даёт −4, а `(-2)^2` даёт 4.
- У каждой формулы собственные параметры. Начальное значение отсутствующего
  параметра равно 1. Ползунок и числовое поле меняют значение в диапазоне
  от −10 до 10 с шагом 0,01.
- При ошибке синтаксиса редактор показывает её позицию. Особые точки,
  например деление на ноль, создают разрывы линии. Поиск разрывов основан
  на выборке значений функции.
- Каждая строка точечной серии содержит X и Y. Маркер появляется после
  ввода двух конечных чисел. Несколько строк с одинаковым X допустимы.
  Перед сохранением исправьте или удалите неполные и ошибочные строки.

Колесо мыши масштабирует область вокруг курсора, перетаскивание левой
кнопкой сдвигает её, а **Fit** подбирает границы по видимым сериям.
Изменения осей сохраняются в документе. **Save As** сохраняет копию.
При замене изменённого документа можно сохранить правки, отбросить
их или отменить действие.

## Формат `.pmplot` v1

Файл хранится как UTF-8 JSON.

```json
{
  "version": 1,
  "viewport": { "xmin": -10, "xmax": 10, "ymin": -2, "ymax": 2 },
  "series": [
    {
      "id": "wave", "label": "Wave", "visible": true, "color": "#5AB0FF",
      "kind": "formula", "expression": "a*sin(x)", "parameters": { "a": 1 }
    },
    {
      "id": "samples", "label": "Samples", "visible": true, "color": "#F2AF57",
      "kind": "points", "points": [[0, 0], [1, 0.84]]
    }
  ]
}
```

Пределы документа — 2 МиБ, 16 серий и 10 000 точек суммарно. Формула
может содержать до 512 символов. Идентификаторы серий должны быть
непустыми и уникальными. Цвет хранится как `#RRGGBB`. Все координаты
и ширина диапазонов должны быть конечными. Нижняя граница каждой оси
должна быть строго меньше верхней. Формулу с синтаксической ошибкой
можно сохранить как черновой текст в валидном документе.

## Реализация и проверки

| Компонент | Studio 4 | Studio 5 |
|---|---|---|
| Интерфейс | [Qt dock и canvas](../ide/plot_editor.py) | [Dockview panel и canvas](../apps/studio/src/features/plot) |
| Вычисление | Парсер `plot_expression.py`, фоновый расчёт с отменой устаревших запросов | Парсер `expression.ts`, Web Worker и отбрасывание устаревших результатов |
| Файлы | `plot_model.py`, запись через временный файл, путь последнего графика в QSettings | [plot_files.rs](../apps/studio/src-tauri/src/plot_files.rs), SHA-256 для обнаружения конфликтов, последний путь в `last-plot.json` |
| Проверки | [Тесты модели](../tools/test_plot_model.py), [тесты формул](../tools/test_plot_expression.py), [Qt smoke](../tools/smoke_qt.py) | [Vitest](../apps/studio/src/features/plot/plot.test.ts) и Rust-тест обмена файлом |

Формулы выполняются в редакторе, а встроенные функции `plot`, `point`,
`line` и `clear` работают при исполнении программы C++ runner'ом.
[Протокол событий VM](PLOT_PROTOCOL.md).
