# Развить PlusMinus в поддерживаемый продукт

## Intent / outcome

Сохранить учебные сценарии написания, запуска и исследования программ и развивать настольную среду на совместимом ядре. Аудитория за пределами учебного применения открыта.

## Success criteria

- Учебные сценарии воспроизводимы по документации; для выбранной продуктовой поставки есть подтверждённая приёмка и согласованные границы поддержки.
