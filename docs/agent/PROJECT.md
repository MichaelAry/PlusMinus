# PlusMinusM

Учебный интерпретатор PlusMinus и настольная среда для написания, запуска и исследования программ. Пользователь подтвердил долгосрочное развитие в продукт. Текущие сценарии включают редактор, тестовую лабораторию, записные книжки, анализ выполнения и графики. Аудитория будущего продукта за пределами учебного применения и сроки открыты.

[README проекта](../../README.md) описывает возможности, зависимости и команды запуска. [Чек-лист Studio 5](../migration/PRE_CUTOVER_VERIFICATION.md) определяет критерии перехода. По наблюдаемой реализации Studio 4 остаётся запуском по умолчанию. Ближайший ориентир сопровождения — приёмка Studio 5 на Windows и Linux x64.
