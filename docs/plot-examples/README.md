# Примеры для Plot Editor

- **Studio 4** — **View → Plot Editor → Open** или общий **Open**.
- **Studio 5** — **Open Plot** в верхней панели, **Plot Editor → Open** или файл `.pmplot` в дереве выбранной рабочей папки. Редактор также открывается из палитры **Ctrl+Shift+P**.

Обе версии используют один формат. Чтобы сохранить свой вариант примера, используйте **Save As**.

| Файл | Что показывает |
|---|---|
| [waves-and-measurements.pmplot](waves-and-measurements.pmplot) | Две формулы и таблица на одном графике. Параметры синусоиды управляют амплитудой (`a`), частотой (`b`) и фазой (`c`). У косинусоиды своё значение `a`. Два замера при `x = 1` показывают, как отображаются точки с одинаковым X. |
| [powers-and-poles.pmplot](powers-and-poles.pmplot) | Парабола через `pow(x,2)` и разрыв у `x = 0.123` в формуле `1/(x-0.123)`. Включите **Steep continuous line**, чтобы сравнить разрыв с крутой непрерывной прямой. Включите **Editable syntax error**, выберите её и исправьте `sin(` на `sin(x)`. Редактор покажет столбец ошибки, а остальные кривые останутся видны. |
| [scatter-and-fit.pmplot](scatter-and-fit.pmplot) | Точечная диаграмма, одиночная калибровочная точка, дальний замер и скрытая линейная модель. Нажмите **Fit**, затем включите **Distant observation** и снова нажмите **Fit**. Чтобы проверить область для одной точки, оставьте видимой только **Single calibration point**. Включите **Linear model** и настройте наклон и смещение через `a` и `b`. |

## Что попробовать в редакторе

1. В первом примере замените значение `a` у синусоиды ползунком и числовым полем. Переключитесь на косинусоиду и сравните её значение `a`.
2. В серии **Measurements** нажмите **Add row** и введите X, затем Y. Маркер появится, когда обе ячейки будут содержать конечные числа. Попробуйте ввести текст вместо числа. Ячейка подсветится, а строку можно исправить или удалить через **Remove row**.
3. Измените имя серии двойным щелчком по её строке в Studio 4 или через поле **Name** в Studio 5. Выберите **Color** и переключите видимость флажком. Через **Add formula** и **Add points** создайте свои серии. В новом документе попробуйте формулы `-2^2` и `(-2)^2`. Они дают горизонтальные линии на высотах −4 и 4. Нажмите **Fit**, чтобы увидеть каждую линию.
4. Увеличьте область около точки колесом и сдвиньте график левой кнопкой мыши. Открепите панель (кнопка **Detach** в Studio 5), сохраните копию через **Save As**, затем снова откройте её и сравните формулы, параметры, таблицы, цвета, видимость и границы осей.
